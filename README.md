# PDF Insight Website

Public-facing website for PDF Insight.

## Stack
- Vite
- Static HTML/CSS
- No backend

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The site is designed to deploy directly to Vercel using the Vite preset.

## Important
Privacy and Terms pages are intentionally placeholders until the actual data-handling and service practices are confirmed.
